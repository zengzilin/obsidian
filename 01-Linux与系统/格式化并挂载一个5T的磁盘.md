# parted挂载超过2T的磁盘


以/dev/sdb 这个目录为例

## 1 使用parted操作/dev/sdb


:::info
parted /dev/sdb

:::



## <font style="color:rgb(77, 77, 77);">2 使用mklable 定义分区表类型</font>
:::info
<font style="color:rgb(77, 77, 77);">(parted) mklabel gpt</font>

:::

**<font style="color:rgb(77, 77, 77);"> </font>**

## **<font style="color:rgb(77, 77, 77);">3.</font>**<font style="color:rgb(77, 77, 77);">使用mkpart创建新分区</font>
:::info
<font style="color:rgb(56, 58, 66);">(parted) mkpart </font>

<font style="color:rgb(56, 58, 66);">Parteition name? []? sdb</font><font style="color:rgb(152, 104, 1);">1</font><font style="color:rgb(56, 58, 66);"> #sdb</font><font style="color:rgb(152, 104, 1);">1</font><font style="color:rgb(56, 58, 66);"> 为自定义分区名称</font>

<font style="color:rgb(166, 38, 164);">File</font><font style="color:rgb(56, 58, 66);"> systenm </font><font style="color:rgb(166, 38, 164);">type</font><font style="color:rgb(56, 58, 66);">? [ext</font><font style="color:rgb(152, 104, 1);">2</font><font style="color:rgb(56, 58, 66);">]? xfs #分区文件类型 按两下Tab可以显示所有文件类型</font>

<font style="color:rgb(166, 38, 164);background-color:rgb(250, 250, 250);">Start</font><font style="color:rgb(56, 58, 66);background-color:rgb(250, 250, 250);">？ </font><font style="color:rgb(152, 104, 1);background-color:rgb(250, 250, 250);">0</font><font style="color:rgb(56, 58, 66);background-color:rgb(250, 250, 250);">% #分区开始位置 </font>

:::

## <font style="color:rgb(56, 58, 66);background-color:rgb(250, 250, 250);"></font><font style="color:rgb(77, 77, 77);">4 使用命令p查看已经分好的区,会显示分区大小及分区文件类型</font>
:::info
(parted) p

:::

## <font style="color:rgb(77, 77, 77);">5退出分区并格式化</font>
:::info
(parted) quit

:::

:::info
  
 mkfs.ext4 -m 0 -E lazy_itable_init=0,lazy_journal_init=0,discard /dev/sdb1

:::

# <font style="color:rgb(56, 58, 66);">挂载磁盘</font>
## 创建挂载目录
:::info
mkdir /data

:::

## 查看/dev/sdb1的UUID
:::info
 blkid /dev/sdb1

:::

## <font style="color:rgb(77, 77, 77);">备份并编辑/etc/fstab</font>
<font style="color:rgb(77, 77, 77);">/etc/fstab 新增挂载信息实现自动挂载</font>

:::info
UUID="364818ad-c523-4e7c-86bd-15613051e8cf" /data ext4 discard,defaults  0 2

:::
