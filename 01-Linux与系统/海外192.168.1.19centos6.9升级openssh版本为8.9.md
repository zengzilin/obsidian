# 1、卸载openssh
      查询系统自带的openssh包



                rpm -qa|grep openssh



      卸载系统自带的openssh包



                rpm -e --nodeps openssh……  （--nodeps为强制卸载，不动用依赖包）



# 2、安装zlib
                解压压缩包



                        tar -zxvf zlib-1.2.11.tar.gz



                 进入目录        



                        cd zlib-1.2.11



                编译并安装



                        1.    ./configure --prefix=/usr/local/zlib



                        2.    make



                        3.    make install



# 3、安装openssl
                解压压缩包



                        tar -zxvf openssl-1.1.1m.tar.gz



                进入目录



                        cd openssl-1.1.1m



                编译并安装



                        ./config --prefix=/usr/local/openssl



                        make



                        make install



# 4、安装pam-devel
                rpm -ivh pam-devel-1.1.1-10.el6_2.1.x86_64.rpm



# 5、安装openssh
                解压压缩包



                        tar -zxvf openssh-9.8p1.tar.gz



                进入目录



                        cd openssh-9.8p1



##   将新编译的openssl library 加入系统动态库连接中


                        vim /etc/ld.so.conf



                添加openssl安装目录



                        /usr/local/openssl/lib



                刷新库文件



                        ldconfig



##  编译并安装


                        ./configure --prefix=/usr/local/openssh --sysconfdir=/etc/ssh --with-ssl-dir=/usr/local/openssl --with-zlib=/usr/local/zlib --with-md5-passwords --without-hardening --enable-dsa-keys --with-pam



                        make



                        make install

## SSH 客户端和 sshd（SSH 服务器守护进程）版本不匹配可能产生以下影响：
+ **连接问题**：
    - **无法连接**：高版本客户端可能使用新协议特性，低版本 sshd 不支持，导致连接被拒绝。例如，客户端支持更高级的加密算法或认证方式，而旧版服务器不识别，无法完成握手。
    - **连接不稳定**：可能出现频繁断开或长时间等待响应的情况。因为不同版本对网络连接的处理机制有差异，在网络状况不佳时，不匹配会使连接难以维持。
+ **安全风险**：
    - **加密强度降低**：旧版本的 sshd 可能使用较弱的加密算法，若搭配高版本客户端，客户端的强加密优势无法发挥，整体通信安全性下降，数据传输易被窃听或篡改。
    - **安全漏洞**：低版本的 sshd 可能存在已知安全漏洞，未及时更新修复，若被攻击者利用，会威胁服务器及连接的客户端安全。
+ **功能受限**：新版本客户端的新功能在旧版 sshd 上无法正常使用，如一些高级的文件传输特性、端口转发功能等，限制了 SSH 的使用体验和效率。
+ **兼容性问题**：不同版本对 SSH 协议的实现细节存在差异，可能导致命令执行结果异常、文件传输错误等问题。例如，在传输文件时可能出现文件损坏或权限设置错误。
