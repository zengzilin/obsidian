# git 拉取远端新分支

![1745300170659-a65bb78b-66d3-4fd5-8b6a-2630ab9a6546.png](./img/s9grO4C2bDEl01E8/1745300170659-a65bb78b-66d3-4fd5-8b6a-2630ab9a6546-574477.png)

本地想要切换分支，但是没有，需要重新拉取，命令：

查看远端分支

git ls-remote --heads origin

拉取全部分支到本地

git fetch --all
