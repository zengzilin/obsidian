# 公有云网络入门（阿里云 + 华为云）

这套资料是给公有云网络初学者准备的，目标不是一下子学全，而是先建立一套能看懂云上网络架构、能和同事对话、能排查基础问题的认知框架。

建议阅读顺序：

1. 先看《01-核心概念与产品映射》：搞清楚名词和它们之间的关系。
2. 再看《02-常见场景与排障思路》：把概念放到真实业务场景里理解。
3. 最后看《03-学习路线与最小知识闭环》：明确接下来怎么学、先学什么。

本目录文件：

- `01-核心概念与产品映射.md`
- `02-常见场景与排障思路.md`
- `03-学习路线与最小知识闭环.md`

如果你只记住一句话：

> 公有云网络的本质，就是“在云上规划网段、连接网络、控制访问、发布服务、打通内外”，而阿里云和华为云只是产品名字不同，底层逻辑高度相似。
